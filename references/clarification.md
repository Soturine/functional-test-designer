# Clarification

Prioritize ambiguity that can change oracle, actor/permission, starting state, trigger, input partition, execution boundary, side effect, procedure, test data, environment, observability, or automation feasibility.

Ask one focused question, record the answer, re-evaluate, and continue for at most five high-impact questions in a normal round. Respect `stop`, `done`, `proceed`, and `skip`.

Answers are internal `USER_CLARIFICATION` evidence with question ID/text, answer, affected refs, and authority interpretation. Never pretend an answer existed in the original sources. Surface conflicts with approved authority; only an explicitly designated authoritative correction may supersede it. Diagnostics contain counts, never answer text.
