## Real dogfood (CP4)

Synthetic lending-library project: `docs/loan-policy.pdf` (functional authority; page 1 has a text layer, page 2 is a single image holding a tier table and the LN-03 renewal diagram — `pypdf` extracts `''` from it), `docs/notes.md` (technical context), `src/loans.py` (implementation, flat limit 3), `tests/test_loans.py` (two existing tests). The expected-obligation list was frozen before the run, by the same agent (not an independent gold).

- **Native reading:** the main model opened the original PDF with the host's PDF reader and read page 2 visually; four located visual facts (two table rows, the diagram, its caption). Reading declared `native_vision`, COMPLETE, 2 pages.
- **Run 1** (before the fixes below): 8/8 gates PASS, manifest verified, output validated; O1–O6 designed; Finding on the flat limit; the reservation setup a blocking Question; the "overdue fees" idea not promoted; the limit-3 existing test not accepted as coverage. 9 READY / 6 NEEDS_REVIEW.
- **Defects found and fixed, initial failures preserved:** (1) a malformed host request crashed instead of being refused; (2) every valid line range on implementation evidence was refused; (3) LN-03, defined only in the diagram, never reached the identifier ledger; (4) the design work order hid how sources were read; (5) self-review: two cases whose setup the implementation makes impossible were labelled READY through an automation-only unknown — contract clarified, payload corrected (no new heuristic).
- **Run 3** (same fixture, unchanged Design and Expansion payloads, cached native catalog reused): ledger now includes LN-03 with its locator; the two cases NEEDS_REVIEW (`UNKNOWN_SETUP_PATH`); 7 READY / 8 NEEDS_REVIEW; 8/8 gates; verified. One diagnostic warning remains (`PROCEDURE_BOILERPLATE`): action templates repeat because the domain has three documented operations; expected results differ per case — not a defect.
- **Observed friction kept as DEFER:** three sound coverage claims were refused on actor wording (containment 0.333 < 0.34); rewording was the escape.
- **ADR, image only:** a scanned decision (PNG) was `UNSUPPORTED` with a native-reading instruction; after a native transcription the round read it, recorded `ADR-004` (Premium limit 5 → 6), updated TC-006/TC-012, left 12 cases untouched, finalized; 0 Azure calls. ## Agent/runtime boundary audit

Method: every production module under `scripts/` and `scripts/integrations/` was inventoried by function; the
responsibilities below were read in their implementation and call sites. Decisions use the directive's vocabulary.
"Read" = implementation and callers read; "Inventoried" = function list and role reviewed, no line-by-line review
(no change was proposed there). A guard was changed only with a reproduced false positive/negative and a test that
fails on the previous code.

## Known limitations

- FTD does no OCR and cannot verify what a reader saw in an image: visual facts and native transcriptions are agent-attested, recorded with their method and digest.
- Native reading quality depends on the host agent; a host that cannot open a format must report FAILED.
- Lexical guards still decide some coverage alignments; the actor/state threshold can refuse sound claims (rewording is the escape).
- Family groups in the report are labelled by scenario id when identifiers are not requirement-like (pre-existing).
- The dogfood, its frozen expectations and the review were by the same agent; there was no independent reviewer.
