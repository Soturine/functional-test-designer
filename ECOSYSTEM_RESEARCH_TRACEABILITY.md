## Cross-project minimum research and evidence

Evaluate actual loaded instructions vs installed runtime, automatic/explicit/non-trigger/coexistence in supported hosts; verify only what the host exposes. Use matched task/model/tools/env/budget, frozen independent oracle and hidden holdout, known-good/bad/ambiguous controls, grader mutation, metamorphic and counterfactual cases, repeated critical stochastic runs. Distinguish pass@k (any success) and pass^k (all success); state sample size and uncertainty; no false green from failed/blocked/incomplete or contaminated trials. Measure correctness, defect detection, precision/recall, false positive/negative, context footprint, time/tokens/cost, retries, human intervention and validated evidence. Actual command/target/revision/version/consent/digests/exit/scope; source reading modality and limits. Observable traces and earliest supported critical failure, typed status/reason/retryability/next useful action; no private reasoning. Checkpoint/recovery and failure injection around effects; selective stale evidence only with verified impact. Feedback records origin, observed evidence, causal hypothesis, scope, affected project, rejected approach, correction, regression and promotion; no automatic rule or release promotion.

External evaluators: [NVIDIA SkillEvaluator](https://docs.nvidia.com/skills/skillevaluator) (Tier 1 structure/security, Tier 2 overlap, Tier 3 real-agent comparison; provider/Docker and optional scanner requirements vary), [Skill Creator](https://github.com/anthropics/skills/tree/main/skills/skill-creator), [OpenAI eval skills](https://developers.openai.com/blog/eval-skills), [harness-aware evals](https://developers.openai.com/cookbook/examples/partners/harness_aware_plugin_evals/harness_aware_plugin_evals), [plugin-eval](https://github.com/openai/plugins/tree/main/plugins/plugin-eval), [AgentRx](https://github.com/microsoft/AgentRx), [agent improvement loop](https://developers.openai.com/cookbook/examples/agents_sdk/agent_improvement_loop), [SkillsBench audit preprint](https://arxiv.org/abs/2611.33943), [Pact](https://docs.pact.io/), [Hypothesis](https://github.com/HypothesisWorks/hypothesis).
